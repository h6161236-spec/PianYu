# 后续优化记录

本文档用于记录 `VCut Studio` 在 V1 完成后的后续优化方向、试用反馈和待办事项。

## 当前阶段

- 当前版本已完成 V1 主流程：
  - 导入视频
  - 中文 ASR
  - 语气词 / 停顿剪辑建议
  - 英文翻译
  - 英文配音
  - 三种导出
  - Windows 发布包与验收清单
- 当前版本已生成 Windows 发布目录与压缩包，可进入真实素材试用阶段。

## 已约定的后续方向

### 1. 真实素材试用后的问题修复

- 用真实中文视频完整走一遍导入、分析、翻译、配音、导出
- 记录识别不准、切点不自然、翻译不顺、配音不贴合、导出异常等问题
- 按试用优先级逐项修复

### 2. 配音确认流程继续优化

- 优化配音确认页的审核体验
- 继续增强“单段确认、单段试听、缓存状态提示、批量处理”的流畅度
- 视试用反馈决定是否增加更细粒度的逐段音色控制

### 3. 导出质量和稳定性优化

- 优化英文配音导出的时长贴合度
- 优化字幕与配音在剪辑后时间线中的一致性
- 提升异常输入、长视频、重复导出的稳定性

### 4. 打包发布继续打磨

- 视需要补 Windows 安装包，而不只是 zip 包
- 继续整理发布目录结构
- 视需要补图标、版本信息、签名等发布细节

### 5. 异常提示和边界场景补强

- 翻译接口失败时的提示优化
- TTS 不可用时的提示优化
- `ffmpeg` / `ffprobe` 缺失时的提示优化
- 配音缓存失效、文件缺失、配置错误时的提示优化

### 6. 配置与安全性优化

- 当前翻译 `API Key` 仍保存在本地设置 JSON
- 后续可考虑接入 Windows Credential Manager 或 DPAPI
