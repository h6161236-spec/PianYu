# 发布验收清单

以下清单适用于 PianYu (片语) Windows 发布前验收。

## 安装与启动

- [ ] `片语.exe` 可直接双击启动
- [ ] 首次启动不闪退、不报阻塞性错误
- [ ] 主界面显示为片语/PPT 口播工作台
- [ ] 菜单中的新建、导入 PPT、打开项目、保存项目、导出视频、设置可正常打开
- [ ] 无管理员权限时也能正常启动和保存用户设置

## 设置页

- [ ] 可保存工作区目录、临时目录和默认输出目录
- [ ] 可保存 `ffmpeg` 路径
- [ ] 可保存 OpenAI-compatible `Base URL`、`API Key`、`Model`
- [ ] 可选择中文 TTS provider 和音色
- [ ] 可选择英文 TTS provider 和音色
- [ ] 可试听当前音色
- [ ] 可设置字幕模式、字号、颜色、安全区和位置
- [ ] 重启后设置仍然保留

## PPT 导入

- [ ] 可导入 `.pptx`
- [ ] 可导入或明确提示 `.ppt`
- [ ] 可提取每页标题、正文、表格文字和备注
- [ ] 可显示幻灯片列表
- [ ] 可显示当前页预览
- [ ] 有 PowerPoint 时优先显示真实页面预览
- [ ] 没有真实预览时可显示文本预览图
- [ ] 导入失败时错误信息可理解

## 口播稿编辑

- [ ] 可整套生成中文口播稿
- [ ] 可只生成当前页中文口播稿
- [ ] 已有中文稿时，重新生成前有覆盖确认
- [ ] 可整套翻译英文口播稿
- [ ] 可只翻译当前页英文口播稿
- [ ] 可手动编辑中文稿和英文稿
- [ ] 切换页面后编辑内容不丢失
- [ ] 保存项目后重新打开，PPT 页面和稿件仍然存在

## 语音输入

- [ ] 当前页可按住录入中文语音
- [ ] 松开后能开始转写
- [ ] 转写结果能追加到当前页中文稿
- [ ] 无麦克风或 ASR 不可用时有明确提示

## 视频导出

- [ ] 可选择中文或英文作为配音语言
- [ ] 缺少对应语言稿件时有明确提示，或一键导出能补齐稿件
- [ ] 可选择输出目录和容器
- [ ] 可导出烧录字幕的视频
- [ ] 可导出 sidecar `.srt`
- [ ] 支持中英双语、仅中文、仅英文字幕模式
- [ ] 字幕位置、颜色、字号符合设置
- [ ] 视频按幻灯片顺序播放
- [ ] 每页画面持续时长与对应配音时长匹配
- [ ] 导出后的视频可正常播放

## 一键导出

- [ ] 可在缺少中文稿时自动生成
- [ ] 可在需要英文稿时自动翻译
- [ ] 可选择 voiceover language、voice、subtitle mode
- [ ] 任务进度、暂停、继续、取消行为正常
- [ ] 取消后不会留下错误的成功提示

## 发布包检查

- [ ] `dist\片语\` 内包含 `片语.exe`
- [ ] 发布目录包含 `README.md`
- [ ] 发布目录包含 `docs\使用指南.md`
- [ ] 发布目录包含 `docs\Windows打包发布.md`
- [ ] 发布目录包含 `docs\发布验收清单.md`
- [ ] 如果选择随包附带 ffmpeg，发布目录中存在 `ffmpeg.exe`
- [ ] 压缩包 `release\片语-windows-v<version>.zip` 可正常解压

## 验收素材建议

- [ ] 5 页以内简单 PPTX
- [ ] 20 页以上真实培训 PPTX
- [ ] 含 speaker notes 的 PPTX
- [ ] 含表格、分组文本、长标题的 PPTX
- [ ] 旧版 `.ppt` 文件

## 发布结论

- [ ] 允许发布
- [ ] 需修复后再发布
- [ ] 仅内部试用，不对外发布
