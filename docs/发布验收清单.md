# 发布验收清单

以下清单适用于 `VCut Studio` Windows 发布前验收。

## 一、安装与启动

- [ ] `VCutStudio.exe` 可直接双击启动
- [ ] 首次启动不会立刻报错或闪退
- [ ] 主界面为中文
- [ ] 首页、时间线、翻译、配音、导出、设置页面都能正常打开
- [ ] 首页依赖扫描能正确显示 `ffmpeg`、ASR、翻译模型、英文配音状态

## 二、设置页

- [ ] 可填写并保存 `Base URL`
- [ ] 可填写并保存 `API Key`
- [ ] 可填写并保存 `Model`
- [ ] 可选择默认英文音色
- [ ] 可调整语速、试听文本、导出默认项
- [ ] 重启软件后设置仍能保留

## 三、导入与分析

- [ ] 能导入 1 个包含中文人声的视频
- [ ] 能正确显示视频分辨率、帧率、是否有音频
- [ ] 能完成中文 ASR 分析
- [ ] 能生成语气词和停顿剪辑建议
- [ ] 双击建议可切换“接受 / 取消接受”
- [ ] “接受全部建议 / 清空接受标记”可正常工作

## 四、翻译流程

- [ ] “测试翻译配置”成功
- [ ] “翻译全部片段”可正常返回英文结果
- [ ] “翻译所选片段”可正常工作
- [ ] 用户可手动修改英文文本
- [ ] 修改英文文本后，后续配音缓存状态会刷新

## 五、配音流程

- [ ] 可在配音页看到每段的缓存状态
- [ ] 可对所选片段应用音色
- [ ] 可试听当前音色
- [ ] 选中某一行时，试听优先使用该行英文文本
- [ ] 可生成所选配音
- [ ] 双击已生成的行可以试听
- [ ] “停止播放”按钮可停止当前音频
- [ ] 修改英文文本或音色后，旧缓存会显示为过期

## 六、导出流程

- [ ] 可导出“纯净中文版视频”
- [ ] 可导出“英文字幕视频”
- [ ] 可导出“英文配音视频”
- [ ] 英文字幕导出时可同时生成 `.srt`
- [ ] 英文配音导出后，原中文背景音不会保留
- [ ] 导出后的视频可正常播放，音画时长大体正确

## 七、异常场景

- [ ] 翻译 `API Key` 错误时会给出明确报错
- [ ] 翻译服务不可访问时会给出明确报错
- [ ] 未选中任何翻译行时，界面提示正常
- [ ] 未选中任何配音行时，界面提示正常
- [ ] 缺少英文文本时，不会误触发配音生成
- [ ] 配音文件被手动删除后，再次试听会提示并重置状态
- [ ] `ffmpeg` 缺失时，导入或导出会给出明确反馈

## 八、发布包检查

- [ ] `dist\VCutStudio\` 内包含 `VCutStudio.exe`
- [ ] 发布目录包含 `README.md`
- [ ] 发布目录包含 `docs\Windows打包发布.md`
- [ ] 发布目录包含 `docs\发布验收清单.md`
- [ ] 如果选择随包附带 `ffmpeg`，发布目录中至少存在 `ffmpeg.exe`
- [ ] 如果发布目录没有 `ffprobe.exe`，媒体探测仍能正常回退到 `ffmpeg`
- [ ] 压缩包 `release\VCutStudio-windows-v<version>.zip` 可正常解压

## 九、人工验收建议素材

- [ ] 15 秒以内短视频 1 个
- [ ] 1 到 3 分钟口播视频 1 个
- [ ] 含明显语气词、停顿的视频 1 个
- [ ] 语速较快的视频 1 个

## 十、发布结论

- [ ] 允许发布
- [ ] 需修复后再发布
- [ ] 仅内部试用，不对外发布
