# 使用指南

PianYu (片语) 用于把 PPT/PPTX 课件制作成带配音和字幕的培训视频。

## 1. 准备

首次使用前建议先打开“设置”：

- 填写 OpenAI-compatible `Base URL`、`API Key` 和模型名
- 设置 `ffmpeg.exe` 路径，或确保 ffmpeg 已加入 `PATH`
- 选择中文和英文 TTS 音色
- 设置默认输出目录
- 按需要调整字幕模式、字号、颜色和位置

如果要获得真实幻灯片截图，请在机器上安装 Microsoft PowerPoint。没有 PowerPoint 时，应用会尽量生成文本预览图。

## 2. 导入 PPT

点击“导入 PPT”，选择 `.pptx` 或 `.ppt` 文件。

导入后应用会：

- 读取幻灯片数量和页面尺寸
- 提取标题、正文、表格文字和备注
- 为每页生成预览图
- 创建一个可保存的本地项目

左侧是幻灯片列表，中间是页面预览和原始内容，右侧是中文稿和英文稿编辑区。

## 3. 生成中文口播稿

可以选择：

- “整套生成中文稿”：为所有页面生成中文讲解
- “生成当前页中文稿”：只处理当前选中的页面

生成时会参考整套 PPT 结构、当前页文本和 speaker notes。已有中文稿的页面重新生成前会提示确认覆盖。

## 4. 翻译英文口播稿

中文稿准备好后，可以选择：

- “整套翻译英文稿”
- “翻译当前页英文稿”

英文稿会按培训讲解口吻翻译，不是逐字硬翻。翻译后仍可手动编辑。

## 5. 手动编辑和语音输入

每页都有独立的中文稿和英文稿。切换页面前，编辑内容会同步到项目中。

如果想自己口述中文稿，可以在当前页按住“按住录入语音”，说完后松开，应用会把转写结果追加到当前页中文稿。

## 6. 导出视频

点击“导出视频”可手动选择：

- 输出目录
- 输出容器
- 配音语言：中文或英文
- TTS provider 和音色
- 字幕模式：中英双语、仅中文、仅英文
- 是否烧录字幕
- 是否同时导出 `.srt`

点击“一键导出”可走引导式流程。它会在需要时自动补齐中文稿、英文稿，再导出视频。

## 7. 输出结果

导出成功后通常会得到：

- 一个视频文件，例如 `.mp4`
- 可选 sidecar `.srt`
- 项目内缓存的每页配音 wav

视频会按幻灯片顺序播放，每页持续时长跟该页配音时长匹配。

## 8. 常见问题

### 没有真实幻灯片预览

确认本机安装了 Microsoft PowerPoint。没有 PowerPoint 时，片语会退回到文本预览图。

### `.ppt` 导入失败

旧版 `.ppt` 需要先转换为 `.pptx`。片语会尝试调用 PowerPoint 或 LibreOffice；如果都不可用，请手动用 PowerPoint 另存为 `.pptx`。

### 无法生成稿件或翻译

检查设置里的 `Base URL`、`API Key`、`Model`，并确认网络能访问对应模型服务。

### 无法导出视频

检查 `ffmpeg.exe` 是否可用，输出目录是否可写，以及选择的配音语言是否已经有完整稿件。

### 没有可用音色

确认本机已准备对应 TTS 资产。大型模型文件不随 Git 仓库提交，通常需要放在 `models/` 下。
